# Kastkeur (beta)

Webapp voor installateurs: groepenkast en woning keuren volgens NEN 1010, metingen vastleggen en keuringsrapport, meetrapport en groepenverklaring als PDF maken.

- Installeer op Android via Chrome: open de site en kies **App installeren**.
- Keuringen staan lokaal op het toestel (IndexedDB). Maak back-ups via Instellingen.
- Foto-analyse van de groepenkast via de Claude API; de API-sleutel vul je in bij Instellingen en blijft op het toestel.

Grenswaarden en bepalingsnummers zijn een hulpmiddel. Controleer ze met je eigen exemplaar van NEN 1010.
